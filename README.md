# dsmailes/homebrew-tap

Homebrew formulae by David Smailes.

## skill-issue

Audit and clean the skills, plugins, MCP servers, instruction files and
caches that AI coding agents leave on your Mac.

```bash
brew install dsmailes/tap/skill-issue
skill-issue          # read-only report
skill-issue tui      # interactive screen to pick items and clean them up
```

**Use at your own risk.** The audit is read-only, but `skill-issue tui` and
`skill-issue clean` move files out of your AI tools' folders. Read the
[disclaimer](https://github.com/dsmailes/skill-issue#disclaimer) before
cleaning anything.

Source and documentation: https://github.com/dsmailes/skill-issue
